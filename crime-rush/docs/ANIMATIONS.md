# In-engine animated scenes
Animation stages reference a configuration in modules/animations/config.js. They render existing image assets on Canvas with a timed eased movement, optional text and confirmation. Reference departure and arrival use the default Pobeditel sprite; future selection context, multiple actors, keyframes, camera and dialogue sequences are not implemented yet. No encoded video required. Common loading UI is in modules/loading/ and used by reference garage/drive; existing game pages retain legacy support for compatibility. Performance: add ?perf=1 to the drive module URL to see measured frame interval p95 and CPU simulation/render p95; report() returns recent 300 frames. Crossroad point checks avoid allocations; rain streaks use cached raster art instead of individual pixels. No measured FPS claim. HUD gear row is decorative, fuel remains decorative, temperature uses existing model. Reference HUD only has new markup; shared CSS/JS retains old temperature needle handling for game pages.
