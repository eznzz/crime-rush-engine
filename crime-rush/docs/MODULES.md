# Modules and missions (alpha.8)
Engine is independent of story content. Composition root: project/manifest.js. Each module owns its entry, config and adapter. Garage and drive are reference modules. Disable a module in manifest and disable/remove dependent missions before removing its directory. Shared assets remain under assets/ for now. Old sandbox URLs redirect.
Mission graph stages: screen (title/text/actions or next), video (src, next, skippable), interior (module,next), drive (module,objective,onSuccess,onFailure,settings). Objective kinds: endless, score, distance (world units), time (simulation seconds). Failure takes precedence. Video URLs are project-relative, use local MP4/WebM. No example video included. A fresh iframe isolates the existing global drive state each run; same-origin message verifies source and stage. No campaign save or cross-scene player inventory yet. Module configurations are classic JS to retain static HTTP hosting; drive settings are mapped to existing controls, not arbitrary physics overrides. Engine still uses legacy DOM bindings, not a general instance API. Future game projects can use their own manifest and host entry; current STANCE CRIME adapter remains unchanged. Browser test required.
