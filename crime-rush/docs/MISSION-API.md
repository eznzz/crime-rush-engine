# Mission API

A project declares modules and a graph of stages. Screen, dialogue, animation, cinematic, event, interior and drive stages are supported. Dialogue accepts lines with speaker/text. Cinematic accepts src and next. Event dispatches crime-rush:mission-event on the mission host. Drive accepts objective and allowlisted settings, with success/failure routes. Game projects provide their own manifest. Events do not automatically grant rewards. The lab runs reference sequences only.
