# CRIME RUSH LIBRARY

Shared assets for CRIME RUSH and independent games. Runtime catalog: `assets/sprites/catalog.js`, registry: `assets/sprites/registry.js`, optional roster: `assets/sprites/extended-roster.js`. `manifest.js` lists original graphic resources. Open `index.html` for preview. The engine keeps the asset loader, not binary sprite copies.

New raster game sprites use lossless WebP. Do not store redundant PNG copies; retain unique source art and PNG platform icons. Existing deleted PNG counterparts remain recoverable from Git history.
