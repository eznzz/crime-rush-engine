# ENVIRONMENT LIBRARY v1

Six independent visual environment presets: rural, forest, village, industrial, city, motorway. These are data definitions only until Phase 3. The legacy rural renderer remains the reference, including all eight existing layer switches. Other presets specify proposed ground/verge colors, enabled legacy layers, and procedural placement rules. No new art is supplied in this change; asset keys are semantic requests for the future renderer catalog. Do not treat them as file paths or available sprites.

Each rule specifies asset key, step in engine world units, per-slot chance [0,1], lateral offset in projected road half-widths (outside the road), scale range, and side. World placement uses seed + asset key + slot + side, independent of camera position and frame rate. The query window is half-open [from,to), maximum length 50000 world units. Stable IDs permit future transition fades and collision-free visual placement; no collision system is connected. Rules are independently distributed: overlap avoidance, continuous guardrails and building spacing are renderer follow-up tasks. RURAL delegates placement to its existing renderer instead of duplicating it.

Environment selection changes only the environment section; road geometry, atmosphere, traffic and event settings remain unchanged. Proposed colors, density, scale and layer switches require visual approval. In particular disabling a visual horse layer does not disable horse gameplay events. All new asset keys (pine, birch, shrub, village-house, village-shed, deciduous-tree, warehouse, industrial-fence, streetlight, city-building, city-tree, guardrail, road-sign) require artwork or explicit procedural renderer implementations. Phase 3 will bind actual art to these keys and connect placement to the perspective renderer, with legacy parity.

## Phase 3A — preview renderer
All six environments selectable in ROAD LAB. Non-rural ground/verge colors and deterministic placements are wired into the existing perspective and depth queue. Provisional procedural sprite rectangles in environment-art.js are deliberately not final artwork. Fog fades silhouettes and ambient light darkens them; exact atmospheric tinting, continuous guardrails, overlap tuning and approved HD sprites are pending. RURAL bypasses new rendering. No mission or standalone game activation. Road geometry and collision rules unchanged.

## Shared roadside catalog
`presets/roadside-assets.js` lists 30 approved sprite IDs grouped by category, with WebP runtime paths. Seed-stable variants selected by world placement ID. FOREST uses pine, birch and shrub variants with fallback to prototype if binary resources have not been imported. Shared guardrail and streetlight are also available in existing non-rural placements. Signs and other assets are catalogued only, not automatically placed. RURAL unchanged. All 30 WebP files are present in LIBRARY. PNG duplicates are not required.

FOREST depth pass: independent seeded back/deep pine and birch placement streams reuse approved sprite variants, offsets 3–9.5 road half-widths. Existing rural verge grass patterns reused in five additional forest rows. New environments close the road polygon at the horizon vanishing point; legacy rural projection unchanged.

Shared original RURAL grass pixel masters moved to `presets/roadside-grass.js`, no raster change. RURAL and FOREST share marker posts spaced 180 world units, both sides; legacy ground unchanged. FOREST has intermittent one-sided guardrail sprite groups and occasional right-side wildlife and forest signs. Chevron is catalogued for future curve-specific placement. Existing connected power lines and HD pole file stay in their existing shared library location. Guardrails are sprite groups, not yet continuous perspective geometry.

Visual distance profile `presets/visibility.js`: recommended trees/buildings/power 2600, signs/barriers 2400, shrubs 2000, grass 1800. Reference mode 1800 for all. Road Lab comparison selector; category-specific fade and cached placement window. No changes to gameplay depth, traffic or road geometry. LOD not implemented in this pass.
