# ENVIRONMENT LIBRARY v1

Six independent visual environment presets: rural, forest, village, industrial, town, motorway. These are data definitions only until Phase 3. The legacy rural renderer remains the reference, including all eight existing layer switches. Other presets specify proposed ground/verge colors, enabled legacy layers, and procedural placement rules. No new art is supplied in this change; asset keys are semantic requests for the future renderer catalog. Do not treat them as file paths or available sprites.

Each rule specifies asset key, step in engine world units, per-slot chance [0,1], lateral offset in projected road half-widths (outside the road), scale range, and side. World placement uses seed + asset key + slot + side, independent of camera position and frame rate. The query window is half-open [from,to), maximum length 50000 world units. Stable IDs permit future transition fades and collision-free visual placement; no collision system is connected. Rules are independently distributed: overlap avoidance, continuous guardrails and building spacing are renderer follow-up tasks. RURAL delegates placement to its existing renderer instead of duplicating it.

Environment selection changes only the environment section; road geometry, atmosphere, traffic and event settings remain unchanged. Proposed colors, density, scale and layer switches require visual approval. In particular disabling a visual horse layer does not disable horse gameplay events. All new asset keys (pine, birch, shrub, village-house, village-shed, deciduous-tree, warehouse, industrial-fence, streetlight, town-building, town-tree, guardrail, road-sign) require artwork or explicit procedural renderer implementations. Phase 3 will bind actual art to these keys and connect placement to the perspective renderer, with legacy parity.

## Final scene art policy
RURAL, FOREST and VILLAGE use approved sprites only in the environment object renderer. Approved shared and village sprites are omitted while loading or if unavailable; no procedural substitute is permitted in any environment for a catalogued sprite. Unfinished environments may retain prototypes only for keys without approved artwork. Forest vegetation, signs and guardrail and Village shared vegetation are preloaded on selection. Approved HD power poles and their connected wires are omitted until the pole image is ready. Intentionally retained original RURAL grass patterns, terrain and other established layers are not prototype substitutes. Projection, density, physics and placement rules are unchanged.
