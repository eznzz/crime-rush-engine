# Static scene standard v1
Scene data belongs to LIBRARY presets or a game; renderer belongs to ENGINE. All asset references use library-relative paths. Coordinates are logical pixels, origin top-left; layers use top-left anchors, actors use bottom-center anchors. Z ascending determines drawing order. Actor height determines proportional width. Ground shadows are rendered separately. Supported atmosphere and time-of-day effects are preview-level overlays, not full lighting simulation. Scene LAB edits actor placement, sprite, view, height, depth and shadow; raw JSON can edit layers. Export is a portable scene definition, not an image. Existing garage and promenade runtime remain unchanged until visual parity is verified. No new sprite files are required.
