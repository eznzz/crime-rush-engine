# Static scene standard v1
Scene data belongs to LIBRARY presets or a game; renderer belongs to ENGINE. All asset references use library-relative paths. Coordinates are logical pixels, origin top-left; layers use top-left anchors, actors use bottom-center anchors. Z ascending determines drawing order. Actor height determines proportional width. Ground shadows are rendered separately. Supported atmosphere and time-of-day effects are preview-level overlays, not full lighting simulation. Scene LAB edits actor placement, sprite, view, height, depth and shadow; raw JSON can edit layers. Export is a portable scene definition, not an image. Existing garage and promenade runtime remain unchanged until visual parity is verified. No new sprite files are required.

Optional character animation: `{type:'breathing',enabled:true,amplitude:0.009,frequency:2.3,lockFeet:true}`. Frequency is angular frequency in rad/s. The same approved split-body renderer is used by the existing scenes. Presets are copied into editor memory; deletion affects only the selected actor in that copy. Export downloads a separate `-copy.json` file; no repository or game writes. Reset restores the selected preset after confirmation.

SCENE LAB v1.2: localStorage catalog `crime-rush.scene-lab.catalog.v1` holds active versions and archive snapshots. Replace archives the previous version in the same write; save-copy requires a unique ID; restore archives the current version and promotes the selected snapshot to a new revision; archive deletion is explicit. Built-in presets remain immutable repository resources. Local changes do not publish to the game; JSON export is the portable backup. Storage is browser-specific and may be cleared by the user.
