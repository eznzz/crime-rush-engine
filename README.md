# Scene Preview v19 — STANCE CRIME

Загрузите папку scene-preview в корень репозитория. Другие файлы репозитория не заменяются.

Фоновые спрайты хранятся в scene-preview/sprites. Автомобиль и персонаж не включены: обе сцены используют общую библиотеку. Для каждого общего ресурса проверяются ../sprites/имя, ../имя, затем те же пути с альтернативным расширением PNG/WebP. Если структура библиотеки отличается, измените ASSETS в соответствующем HTML. При отсутствии ресурса выводится список проверенных путей.

Необходимые общие ресурсы (или альтернативный PNG/WebP):

- left.png
- leftmini.png
- man-back.webp
- man-front.webp
- man-side.webp
- man-three-quarter-back.webp
- man.webp
- rear.png
- right.png
- rightmini.png
- side.webp

Оригинальные фоновые файлы v18 сохранены без изменения. Солнце статической сцены 58 × 58, маска памятника исправлена. GitHub вернул только LICENSE; пути общих ресурсов являются предположением, а не подтверждённой структурой.
